# Roadmap

- Phase 1 complete: bootstrap, CLI, configuration, IPv4 interfaces, health, and doctor.
- Phase 2 complete: native SSDP, parser, scan CLI, and tests.
- Phase 3 complete: safe UPnP HTTP/XML, logical-device registry, merging, provenance, and optional CLI enrichment.
- Phase 4 complete: browser scans, inventory API/templates, Bootstrap 5, HTMX, and bounded SSE; local assets embedded in the binary.
- Phase 5 complete: optional bounded Nmap host discovery, validated XML, and manual TCP enrichment of individual known IPs.
- Phase 6: review RTK integration, documentation, and MVP validation.

0.1 includes all phases above and is not complete yet.
0.2: mDNS, ARP, SMB/NFS discovery.
0.3: DLNA ContentDirectory, browsing, and MediaRenderer.
0.4: WebDAV, fingerprinting, and confidence scoring.
0.5: persistence, history, comparison, and topology.
